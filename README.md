# 保险经销业务 PVI 自动化报表分析工具

## 项目背景

本项目面向保险经销业务日常经营管理场景，将每日保单汇总列表和代理人信息表自动加工为多页签 Excel 经营报告，减少人工筛选、汇总和重复制表工作。

## Demo

Streamlit Demo: https://insurance-pvi-report-assistant.streamlit.app/

## 核心功能

- 支持上传 `保单汇总列表*.xlsx` 和 `代理人信息*.xlsx/.xls`
- 自动完成字段清洗、日期解析、PVI 数值转换和有效保单状态过滤
- 内置业务口径修正：陕西分公司归入大湾区计划；虚拟总监陕西按管理/服务字段回填真实归属
- 自动生成安盛活力星达成追踪、阳光联动追踪、MDRT、MDRT-区域、属地代理人达成情况等专题 Sheet
- 输出区域累计 PVI、机构团队月度 PVI、机构团队月度入职人数和三类全年明细
- 支持页面配置报告月份、累计统计月份和补算日期
- 使用 OpenPyXL 自动设置 Excel 标题、筛选、列宽、边框、数字格式和右侧汇总表
- 已移除旧版图片看板、月度目标缺口、目标达成率、信泰旧方案和内嵌图片逻辑

## 输出 Sheet

- 安盛活力星达成追踪
- 阳光七八联动追踪
- MDRT
- MDRT-区域
- 大湾区属地代理人达成情况
- 区域累计月份 PVI 汇总
- 机构团队月度 PVI 汇总
- 机构团队月度入职人数
- 大湾区凯旋明细（全年）
- 曜坤区明细（全年）
- 方圆区总部直辖明细（全年）

## 技术栈

Python、Pandas、OpenPyXL、Streamlit、Git/GitHub

## 本地运行

```bash
pip install -r requirements.txt
streamlit run streamlit_app.py
```

## 数据安全说明

真实业务数据中可能包含代理人工号、代理人姓名、保单号、投保单号等敏感信息。对外展示和部署 Demo 时，建议只使用脱敏样例数据，并删除或替换真实姓名、工号、保单号、投保单号等字段。
